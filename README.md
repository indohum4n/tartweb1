# Kue Tart Turen — Official Website

A responsive website for Kue Tart Turen, a local homemade cake business established in 2019. The website showcases cake collections, provides business information, and helps customers explore available products and place orders.

**Live Demo:** [kuetartturen.netlify.app](https://kuetartturen.netlify.app/)

## Features

- **Cake Gallery** — Browse a collection of handmade cakes and custom designs.
- **Responsive Design** — Optimized for desktop and mobile devices.
- **Business Information** — Learn about the business, location, and contact details.
- **Order Navigation** — Quick access to the contact section for order inquiries.
- **Product Showcase** — Dedicated visuals for different cake varieties.

## Tech Stack

- **HTML5** — Website structure and semantic markup.
- **CSS3** — Styling, layouts, animations, and responsive design.
- **JavaScript** — Interactive functionality and client-side behavior.
- **Netlify** — Website deployment and hosting.

## Getting Started

### Run Locally

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd kue-tart-turen
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

## Deployment

The website is deployed using Netlify.

To deploy your own version, connect your GitHub repository to Netlify and configure the publishing directory to the project root if the website is a static HTML, CSS, and JavaScript project.

## Project Goals

This project was built to establish an online presence for a local cake business, showcase its products, and provide customers with an accessible way to find business information and make order inquiries.
